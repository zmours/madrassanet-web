Questions fréquentes

Les réponses aux questions les plus courantes des utilisateurs.

📱 Application mobile

Comment télécharger l'application MadrassaNET ?

L'application est disponible gratuitement sur l'App Store (iPhone/iPad) et Google Play (Android). Recherchez "MadrassaNET" ou utilisez les liens sur la page d'accueil.

Je n'arrive pas à me connecter. Que faire ?

Vos identifiants (e-mail et mot de passe) sont créés par l'administrateur de votre établissement. Si vous n'arrivez pas à vous connecter, contactez d'abord votre administrateur d'école. Si le problème persiste, utilisez notre formulaire de contact.

L'application peut-elle fonctionner sans Internet ?

L'application nécessite une connexion Internet pour se synchroniser. Certaines données peuvent être consultées hors-ligne si elles ont été préalablement chargées, mais la saisie (présences, notes) nécessite une connexion.

Comment activer les notifications push ?

Lors de la première connexion, l'application vous demande la permission d'envoyer des notifications. Si vous avez refusé, rendez-vous dans les Paramètres de votre téléphone > Notifications > MadrassaNET pour les réactiver.

Comment changer d'école dans l'application ?

Sur l'écran de connexion, un bouton "Changer d'école" vous permet de sélectionner un autre établissement. Chaque école a son propre espace indépendant.

👨‍🏫 Enseignants

Comment saisir les présences de mes élèves ?

Dans l'application, accédez à la section "Présences" → choisissez votre classe → sélectionnez la date → marquez chaque étudiant (présent/absent/retard). Validez en bas de l'écran.

Comment saisir les notes d'un examen ?

Accédez à la section "Notes" → sélectionnez votre classe et la matière → créez un examen ou choisissez-en un existant → saisissez les notes pour chaque étudiant. Les moyennes sont calculées automatiquement.

👨‍👩‍👧 Parents & Étudiants

Comment consulter les notes de mon enfant ?

Connectez-vous avec votre compte parent → accédez à la section "Notes" → sélectionnez votre enfant si vous en avez plusieurs. Les notes et moyennes s'affichent par matière et par période.

Comment télécharger le bulletin scolaire ?

Accédez à la section "Bulletins" → sélectionnez la période (semestre/trimestre) → appuyez sur "Télécharger". Le bulletin au format PDF s'enregistre dans vos fichiers.

Je ne vois pas les données de mon enfant. Pourquoi ?

Vérifiez que votre compte parent est bien lié à votre enfant. Si ce n'est pas le cas, contactez l'administrateur de l'école qui pourra faire le rattachement.

🏫 Administrateurs

Comment importer des étudiants en masse ?

Accédez à "Étudiants" → "Importer" → téléchargez le modèle Excel → remplissez-le → importez le fichier. Un aperçu de validation s'affiche avant confirmation. Consultez la page des modèles pour télécharger les templates.

Comment configurer le logo de mon établissement ?

Accédez aux "Paramètres" → "Paramètres de l'école" → "Personnalisation" → téléchargez votre logo. Il apparaîtra dans les bulletins PDF, les factures et sur l'écran de connexion de l'application mobile.

Comment générer les bulletins de fin de période ?

Accédez à "Bulletins" → "Générer les bulletins" → sélectionnez la classe et la période → cliquez sur "Générer". Les bulletins PDF sont créés automatiquement avec les moyennes calculées.

Comment créer des factures pour les familles ?

Accédez à "Finance" → "Factures" → "Nouvelle facture" → choisissez le type (Famille ou Individuel) → sélectionnez les frais applicables → générez. Les factures PDF sont disponibles immédiatement.

🔒 Compte & Sécurité

Comment changer mon mot de passe ?

Dans l'application, accédez à votre Profil (icône en haut à droite) → "Sécurité" → "Changer le mot de passe". Entrez votre mot de passe actuel puis le nouveau.

Comment supprimer mon compte ?

Consultez notre page dédiée : Supprimer mon compte. La procédure est simple et vos données seront supprimées sous 30 jours.

Mes données sont-elles sécurisées ?

Oui. MadrassaNET utilise le chiffrement HTTPS, des tokens JWT sécurisés, et chaque établissement dispose d'un espace de données strictement isolé. Voir notre Politique de Confidentialité.
