📥 Import de données

Guide pour importer vos données dans MadrassaNET

Ces modèles sont fournis pour faciliter l'import de données dans MadrassaNET. Ils sont réservés à un usage interne par les administrateurs des établissements.

📖 Comment importer vos données

Téléchargez le modèle correspondant

Choisissez le modèle (.xlsx) adapté au type de données à importer ci-dessus.

Remplissez le fichier Excel

Complétez les colonnes en respectant les formats indiqués dans la ligne d'exemple. Ne modifiez pas les en-têtes de colonnes.

Importez dans MadrassaNET

Dans l'administration web : section correspondante → bouton "Importer" → sélectionnez votre fichier.

Validez l'aperçu

MadrassaNET affiche un aperçu avec les erreurs éventuelles avant l'import définitif. Corrigez si nécessaire.

Confirmez l'import

Cliquez sur "Confirmer l'import". Les données sont ajoutées à votre établissement.

💡 Besoin d'aide pour l'import ? Consultez notre centre de support ou contactez-nous via le formulaire.
